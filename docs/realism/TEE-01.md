# Foundation / TEE 01

Abaya development is paused, not deleted. The next progression is one neutral short-sleeved crew-neck tee on a fixed mannequin; then only after acceptance, trousers, then abaya complexity.

## Scope
- Original generic tee construction, **not** a replica of a supplied product. The UI flat drawing is an authored brief, not a garment photograph or production pattern.
- Continuous front/back with shared-index sleeve armholes, open neck/hem/cuffs, matte finite-thickness surfaces and a simple collar/hem band.
- Original uncalibrated statistical mannequin, intact body mesh. A dark surface material zone below the shirt is a modesty finish, **not** the later trousers prototype.
- Neutral clay first, optional off-white illustration; front/back/side/three-quarter/neck/underarm inspection cameras.
- Offline Blender drape is an engineering experiment, not a calibrated cotton model or live fitting. The actual executed frame count, motion samples and raw nearest-plane body diagnostic are in the restored report.

## Rejected first experiment
The initial 72-frame drape had a mirrored local frame on one sleeve, causing severe twisting/bunching and exposing the upper arm through the resulting distorted opening. It was rejected visually despite low vertex diagnostic counts. The report is retained as `verification/tee-01/rejected-first-solve.json`. The sleeve frame was corrected to point upward on **both** sides; pre-solve assertions now guard that invariant. More wrinkles are not a quality gate.

## Construction refinement
A second, correctly oriented solve still had excessive ease and bunching. The torso profile was narrowed and the collar material band was restricted to torso faces, removing accidental sleeve stripes. The prior run report remains as `verification/tee-01/loose-solve.json`. The final viewer is still a review candidate, not an approved garment.

## Acceptance remains separate
Topology checks require one connected shell, exactly four non-branching opening loops, no edge with more than two incident faces, intact mannequin faces and correct sleeve frame orientation. They do not prove a convincing tee or a collision-free drape. Browser smoke checks are separate from visual assessment. Neither product likeness, physical calibration nor fit is accepted.

Human review must inspect shoulder/armhole, collar, chest/back drape and hem on the fixed body before starting any variable-size behavior. Real garment dimensions and a product reference will be needed before claiming product fidelity or sizing accuracy.

## Build
```
npm install
npm run build:tee
# Open dist/maka-tee-01.html in a full WebGL browser.
CHROMIUM_PATH=/path/to/chromium npm run test:tee:browser
```
The file embeds fonts, libraries, body and shirt and works offline. No hosting deployment is implied.

## Reauthor (Blender 4.5 installed separately)
```
npm run build
node tools/pilot/export_body.mjs
/path/to/blender -b --python tools/pilot/create_tshirt.py -- --frames 96
python3 tee/pack.py
npm run build:tee
```
The checksummed pack contains the complete GLB, unsimulated construction GLB, editable Blender source **before** time stepping, executed-run report and topology report. Simulation point-cache history is regenerated by the script, not required for the viewer. Reauthoring does not imply a new visual acceptance. Earlier abaya and baseline pages/packs are unchanged.
